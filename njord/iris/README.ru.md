# Iris — приёмник Njord на станции

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Цифры проверяются по даташитам и самим компонентам, прежде чем будет сделана плата.

**Iris приводит поле на станцию: MOD на ветви Palatine, ModBus тип 8, радиошлюз.** Она принимает
каждый блок Njord в пределах досягаемости, подтверждает каждый, держит такт их слотов и хранит
последнюю запись каждого блока в окне регистров, которое Palatine читает как любой датчик. **Каждый
полевой блок — мультидатчик за адресом Iris**, так же как Palatine уже читает покупную коробку многих
величин одним блоком (газы Chinook): первый регистр блока — номер блока, остальное — его значения, а
профиль блока — по типу Iris и этому номеру — говорит, что значит каждый регистр.

**Одна плата, две роли.** Та же плата в поле — **[Arke](arke/)**; какая из двух, она определяет при
первом запуске по току своего коммутируемого выхода и помнит это, пока её не сбросит магнит.
