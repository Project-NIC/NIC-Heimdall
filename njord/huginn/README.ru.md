# Huginn — шлюз Njord в интернет

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Цифры проверяются по даташитам и самим компонентам, прежде чем будет сделана плата.

**Huginn принимает блоки Njord там, где нет станции, и отправляет их данные дальше через интернет** —
маленький блок с LoRa и Wi-Fi у окна или на балконе, с питанием от USB. Для блоков это приёмник, как
Iris: он подтверждает, держит такт их слотов, несёт обратно настройку; для интернета это клиент,
который отправляет каждую запись блока в формате полевого блока на заданный ему сервер. Шлюз LoRaWAN
делает то же с сетевым сервером за ним; Huginn он не нужен.

| | |
|---|---|
| плата | ESP32-S3 с Wio-SX1262 (набор Seeed XIAO ESP32-S3 & Wio-SX1262, покупной) |
| радио | один канал и один spreading factor за раз, перестраивается в слоте каждого блока — собственному пакету Njord не нужен восьмиканальный концентратор LoRaWAN |
| uplink | Wi-Fi; запись отправляется на сервер, заданный на его странице |
| время | NTP через его Wi-Fi — от миллисекунд до десятков — отметка прихода каждого пакета; возраст от блока даёт время измерения |
| настройка | собственная веб-страница на собственной точке доступа WPA2, открытой только для настройки: сеть, сервер, ключи блоков и их слоты |
| питание | 5 В от USB |
| связь | [`../LINK.md`](../LINK.md) |

**Один Huginn держит много блоков:** его эфир — подтверждения, ~7 800 в час на SF7 в пределах 10 %
диапазона h1.7. Число задаёт дальность, а не эфир: блок в метре над травой достаёт до Huginn у окна
на несколько километров на открытой местности, меньше — через деревья и стены (`LINK.md` §1).
