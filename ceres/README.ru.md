# Ceres — датчик влажности почвы

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Цифры проверяются по даташитам и самим компонентам, прежде чем будет сделана плата.

**Ceres измеряет объёмное содержание воды в почве на эталонной глубине WMO и температуру почвы там
же: ModBus тип 6, MOD на ветви ModBus Palatine.** Гребенчатый электрод на нижней стороне платы
измеряет сквозь 1 mm боросиликатного стекла — плата залита в боросиликатную чашу гребёнкой вниз, со
стеклом с обеих сторон — и читается как адмиттанс на трёх частотах: квадратурная составляющая — это
вода, синфазная — ионы, а частоты разделяют одно и другое. Блок отвечает готовым скомпенсированным
значением. Несколько блоков лежат в земле в **патроне** — трубе, набитой на верстаке и забитой в
землю целиком (`../palatine/CONSTRUCTION.md`, *The soil column*), и именно это делает глубину
повторяемой от станции к станции.

| | |
|---|---|
| класс | **собственный MOD** — ведомое устройство Modbus RTU на ветви Palatine, **ModBus тип 6**, адрес `6«2 \| NUMBER`, 0x18 для блока 0; часов нет, хост ставит метку времени на показание при опросе |
| что он сообщает | содержание воды в `0x0000`, температуру почвы на этой глубине в `0x0001` — один блок, один адрес, два значения (`MODBUS.md`) |
| чувствительный элемент | собственная гребёнка платы под стеклом чаши, горизонтально в утрамбованном песке патроны, стеклом вниз |
| измерение | синхронный детектор на 2²⁰ / 2²² / 2²⁴ Hz — 1,05 / 4,19 / 16,8 MHz — относительно опорного конденсатора через ту же цепочку (`HARDWARE.md`) |
| компоненты | `STM32H523VE` · `THS4541` · 3× `74LVC1G3157` · `74LVC1G17` · `TMP117` или `STS35` · `THVD1450` · `LMR43610` |
| глубины | стандартный ряд 5 · 10 · 20 · 50 · 100 cm — пара для станции −10 и −50 cm, профиль для фермы −10 · −20 · −50 · −100 cm; какие глубины несёт станция — решение по культуре и площадке |
| питание | изолированные 12 V ветви по четырёхпроводному кабелю, как у каждого датчика на ветви; плата сама делает свои 3,3 V |
| кабель | плоский, четыре проводника, припаян к плате и залит через канал чаши; разъёма на блоке нет |

**Sakura — та же плата в той же чаше, подвешенная в пологе растений** — `sakura/`.

## Структурная схема

```
   a Palatine arm ── A · B · 12 V · GND ── the flat cable, up the patrona
        │
   ┌────┴─────────────────────────────────────────────────────────────────────────┐
   │ CERES — the board potted in a borosilicate bowl                              │
   │  H523 · THVD1450 · the detector chain                                        │
   │  the comb on the underside ── 1 mm of glass ── the packed sand at the depth  │
   │  the thermometer on the board ── the soil temperature there                  │
   └──────────────────────────────────────────────────────────────────────────────┘
```

## Дерево

```
ceres/       Ceres — soil moisture and the soil temperature at its depth  ModBus 6
└── sakura/  Sakura — leaf wetness, Ceres's board in the same bowl        ModBus 7
```
