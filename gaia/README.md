# Gaia — where the stations go

> **Design-stage concept — nothing built.** The figures are verified against the parts' sheets and
> the parts before a board is made. **All coordinates are approximate and representative — a siting
> guide, not survey data.**

**Gaia is the map of dots: where stations go across the Earth, at what density, and on what is
already there.** The unit of design is one station; membership of a network is a property of
deployment, and the data goes to the networks that exist (`../core/INTEROP.md`). How a station is
built and seated is `../daedalus/CONSTRUCTION.md`'s; what goes into the water is
`../atlantis/README.md`'s.

**The gap it fills.** The world's ground networks are small and lopsided: GSN ~150 seismic stations,
INTERMAGNET ~120 magnetic observatories, IGS ~530 GNSS references, DART 74 tsunami buoys — and of
the roughly 10–15 k live professional seismic stations a third sit in Japan and the US, while whole
populated hazard belts — India, Turkey, Iran, Indonesia, East Africa — run nearly bare. Not more
stations where there are many: **first stations where there are none.**

```
   GeoNames towns × the hazard lines ──▶ siting rules 1–6 ──▶ the first wave, ordered by global blindness
                                                           ──▶ COMPLEMENT where nothing is in reach
                                                           ──▶ DENSIFY where the spacing is ~100 km
   the loadout follows the site; the density follows the field
```

## The maps

- **One file at a time** — GitHub draws any `.geojson` below as an interactive map.
- **All layers together** — `index.html` loads every layer into one Leaflet map with a layer
  switcher; it runs on GitHub Pages (Settings → Pages → Deploy from `main`, root) at
  `https://<org>.github.io/<repo>/gaia/`. Leaflet is vendored in `vendor/`, so only the map tiles are
  fetched online.
- **Static snapshots** beside the units that use them — `tesla/pip/coverage.svg`,
  `quake/coverage.svg`, `gauss/coverage.svg` — generated by `tools/gen_coverage_svg.py`; the GeoJSON
  is the authority, and the script is rerun after a layer changes.

Styling is [simplestyle-spec](https://github.com/mapbox/simplestyle-spec), so the files render alike
in GitHub's viewer and in the combined map.

## Files

| file | contents |
|---|---|
| [`SITING.md`](SITING.md) | the six siting rules, the two deployment roles, the two tiers, density and loadout, the computed first wave, the islet-first rule, why the network can be placed |
| [`DATA.md`](DATA.md) | the public datasets the maps stand on |
| [`WHY.md`](WHY.md) | the graveyard |
| [`proposed-network.geojson`](proposed-network.geojson) | **the deployment** — the computed first wave, marker by marker, each with its loadout and unit count; coastal markers carry the threat bearing, the cable length to the slope toe and the toe depth, and snap to a named islet where one sits seaward on the slope |
| [`existing-systems.geojson`](existing-systems.geojson) | a representative subset of today's global networks — DART · GSN · INTERMAGNET · IGS · CTBTO |
| [`priority-tsunami.geojson`](priority-tsunami.geojson) | the major subduction trenches and the island-arc array sites, each with the sector its fan points at |
| [`priority-earthquake.geojson`](priority-earthquake.geojson) | the continental seismic belts and the high-exposure, under-instrumented cities |
| [`priority-tec.geojson`](priority-tec.geojson) | where GNSS-TEC earns most — the equatorial anomaly crests and the auroral ovals |
| [`priority-radiation.geojson`](priority-radiation.geojson) | the best sites for the neutron heads as a cosmic-ray monitor — low geomagnetic cutoff, high altitude; the weakest priority geography |
| [`longwave-transmitters.geojson`](longwave-transmitters.geojson) | the 34–120 kHz services Pip can hear — blue the time-code stations (DCF77 · MSF · WWVB · RBU · BPC · JJY), a full date once a minute on a caesium-derived carrier; amber eLoran at 100 kHz, time to ~100 ns and no calendar. The circles are nominal free-field reach; the receiver's surroundings decide (`SITING.md`, rule 6). Most of the planet has no longwave time |
| [`bathy-per-site.csv`](bathy-per-site.csv) | measured bathymetry for 121 of the 168 coastal sites (ETOPO); 47 are schematic trench lines too far from real land, and Slab2 is the fix (`DATA.md`) |
| `tools/` | `gen_network.py` · `gen_priority.py` · `gen_bathy.py` · `gen_coverage_svg.py` — the scripts that compute the layers |
| `index.html` · `vendor/` | the combined map |
