# Gaia — где ставить станции

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Цифры проверяются по даташитам и самим компонентам, прежде чем будет сделана плата. **Все координаты приблизительные и показательные — ориентир для размещения, а не данные съёмки.**

**Gaia — это карта точек: где по всей Земле ставить станции, с какой плотностью и с опорой на то,
что уже есть.** Единица проектирования — одна станция; членство в сети — свойство развёртывания, и
данные идут в те сети, которые существуют (`../core/INTEROP.md`). Как станция строится и
устанавливается — это `../daedalus/CONSTRUCTION.md`; что идёт в воду — `../atlantis/README.md`.

**Пробел, который она заполняет.** Мировые наземные сети малы и перекошены: GSN — ~150 сейсмических
станций, INTERMAGNET — ~120 магнитных обсерваторий, IGS — ~530 опорных станций GNSS, DART — 74
буя цунами, а из примерно 10–15 k действующих профессиональных сейсмических станций треть стоит в
Японии и США, тогда как целые населённые пояса опасности — Индия, Турция, Иран, Индонезия, Восточная
Африка — почти пусты. Не больше станций там, где их много: **первые станции там, где их нет.**

```
   GeoNames towns × the hazard lines ──▶ siting rules 1–6 ──▶ the first wave, ordered by global blindness
                                                           ──▶ COMPLEMENT where nothing is in reach
                                                           ──▶ DENSIFY where the spacing is ~100 km
   the loadout follows the site; the density follows the field
```

## Карты

- **По одному файлу** — GitHub отображает любой `.geojson` ниже как интерактивную карту.
- **Все слои вместе** — `index.html` загружает все слои в одну карту Leaflet с переключателем
  слоёв; она работает на GitHub Pages (Settings → Pages → Deploy from `main`, root) по адресу
  `https://<org>.github.io/<repo>/gaia/`. Leaflet включён в `vendor/`, поэтому из сети загружаются
  только тайлы карты.
- **Статические снимки** рядом с блоками, которые их используют, — `tesla/pip/coverage.svg`,
  `quake/coverage.svg`, `gauss/coverage.svg` — генерируются скриптом `tools/gen_coverage_svg.py`;
  первоисточник — GeoJSON, и после изменения слоя скрипт запускается заново.

Оформление следует [simplestyle-spec](https://github.com/mapbox/simplestyle-spec), поэтому файлы
выглядят одинаково и в просмотрщике GitHub, и на объединённой карте.

## Файлы

| файл | содержание |
|---|---|
| [`SITING.md`](SITING.md) | шесть правил размещения, две роли в развёртывании, два уровня (tiers), плотность и комплектация, рассчитанная первая волна, правило «сначала островок», почему сеть можно разместить |
| [`DATA.md`](DATA.md) | открытые наборы данных, на которых стоят карты |
| [`WHY.md`](WHY.md) | кладбище — что пробовали, что отвергли и почему |
| [`proposed-network.geojson`](proposed-network.geojson) | **развёртывание** — рассчитанная первая волна, маркер за маркером, каждый со своей комплектацией и числом блоков; прибрежные маркеры несут азимут угрозы, длину кабеля до подножия склона и глубину подножия и привязываются к названному островку там, где он лежит на склоне со стороны моря |
| [`existing-systems.geojson`](existing-systems.geojson) | представительная выборка сегодняшних глобальных сетей — DART · GSN · INTERMAGNET · IGS · CTBTO |
| [`priority-tsunami.geojson`](priority-tsunami.geojson) | основные субдукционные желоба и площадки массивов зондов на островных дугах, каждая с сектором, на который направлен её веер |
| [`priority-earthquake.geojson`](priority-earthquake.geojson) | континентальные сейсмические пояса и города с высокой подверженностью и недостаточным приборным покрытием |
| [`priority-tec.geojson`](priority-tec.geojson) | где GNSS-TEC даёт больше всего — гребни экваториальной аномалии и авроральные овалы |
| [`priority-radiation.geojson`](priority-radiation.geojson) | лучшие места для нейтронных головок в роли монитора космических лучей — низкая геомагнитная жёсткость обрезания, большая высота; самая слабая из приоритетных географий |
| [`longwave-transmitters.geojson`](longwave-transmitters.geojson) | службы 34–120 kHz, которые слышит Pip, — синим станции кода времени (DCF77 · MSF · WWVB · RBU · BPC · JJY), полная дата раз в минуту на несущей, полученной от цезиевого эталона; янтарным eLoran на 100 kHz, время с точностью ~100 ns и без календаря. Круги — номинальная дальность в свободном пространстве; решает окружение приёмника (`SITING.md`, правило 6). На большей части планеты длинноволнового времени нет |
| [`bathy-per-site.csv`](bathy-per-site.csv) | измеренная батиметрия для 121 из 168 прибрежных площадок (ETOPO); 47 — схематические линии желобов слишком далеко от реальной суши, и исправление для них — Slab2 (`DATA.md`) |
| `tools/` | `gen_network.py` · `gen_priority.py` · `gen_bathy.py` · `gen_coverage_svg.py` — скрипты, которые рассчитывают слои |
| `index.html` · `vendor/` | объединённая карта |
