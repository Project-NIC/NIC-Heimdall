# Neutron — нейтронный канал на фотоумножителе

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Головка, экраны и считывание → [`HARDWARE.md`](HARDWARE.md); плата, на которую он ставится → [`../positron/HARDWARE.md`](../positron/HARDWARE.md); кладбище — что пробовали, что отвергли и почему → [`WHY.md`](WHY.md).

**`Neutron` считает нейтроны в низковольтном варианте**: сборка из двух экранов `⁶LiF/ZnS(Ag)` с замедлителем из PMMA между ними, считываемая фотоумножителем класса 3–5 дюймов, анод которого — на **канале 1 `Quark-Neutron/Positron`**. Амплитуда каждого импульса говорит, какой экран сработал, поэтому он даёт **два счёта — тепловой и эпитепловой — и никакой энергии**.

**Он едет в записи Positron**: два счёта — это байты 8–11 записи Positron размером 32 B, два `uint16` перед его десятью полосами (`../photon/BUS.md`), под NUMBER Positron, потому что четыре байта — это весь канал. **NodBus тип 10 зарезервирован для него**: сборка, которой нужен `Neutron` на собственном NUMBER, берёт тип 10, и больше ничего на плате не меняется.

**Его высокое напряжение — kV-источник Helion** (`../../tubes/helion/`), собранный для этой головки: три ступени умножителя, отвод ~1200 V, тактирование по `SYNC` от платы.

```
   screen · PMMA · screen ──▶ photomultiplier (kV source, ~1200 V) ──▶ THS4551 ──▶ Quark-Neutron/Positron, channel 1
                                                                                  ──▶ thermal · epithermal, in Positron's record
```
