# Sputnik — ионосферный GNSS-фронтенд и время станции

[English](README.md) · [Čeština](README.cs.md) · **Русский**

> **Концепция на стадии проектирования — ничего не построено.** Цифры проверяются по даташитам и самим компонентам, прежде чем будет сделана плата.

**Sputnik читает ионосферу по GNSS: NodBus тип 8, NOD.** Один многосистемный многочастотный приёмник
Unicore **UM980** и один STM32H523 на одной плате. Он передаёт потоком сырые наблюдения каждого
отслеживаемого спутника на трёх частотах — псевдодальность, фазу несущей, SNR — с частотой 5 Hz,
по которым вычисляется **полное электронное содержание** на каждом луче над станцией, а вместе
с приземной метеорологией Palatine — **осаждаемый водяной пар**.

**Тот же приёмник — источник времени GNSS для станции.** Его PPS и экономный поток NMEA идут
в Kronos через второй разъём платы; на станции со Sputnik больше ничего не ставится, а станция без
него ставит Polaris (`../kronos/polaris/`). Kronos остаётся источником истины, который подстраивает
и распределяет, — UM980 лишь его источник.

## Как он подключён к станции

- **Всегда в корпусе** — антенна установлена с обзором неба на собственной мачте станции, и длинный
  только коаксиальный кабель (`../core/blocks/gps-pps.md`, *The receiver lives in the enclosure*).
  Оба разъёма тогда принимают перекрёстный кабель внутри корпуса: разъём NodBus — к порту карты,
  временной порт — к разъёму приёмника на Kronos. Оба также рассчитаны на то, чтобы принять по
  линии Galvani, причём временную линию в обратном направлении — PPS внутрь к Kronos, — и Kronos
  измеряет её дальность.
- **Вверх: NodBus, пять NUMBER, пять слотов** — одна очередь, которую H523 заполняет фрагментами
  по 32 B из эпох по 200 ms; ведущий собирает их по индексу кадра и порядку слотов, а PRN каждой
  записи указывает её спутниковую систему.
- **Вбок: временной порт к Kronos** — PPS приёмника по каналу B прямо с его вывода, поток
  `RMC`/`GGA`, ретранслируемый по каналу A, обслуживается, пока отвечает heartbeat Kronos. **`END`
  завершает измерительную часть, но никогда не ретрансляцию**: источник времени станции уходит
  только вместе с полной блокировкой.

```
   the antenna ──coax──▶ ┌────────────────────────────┐ ── NodBus, type 8, five NUMBERs ──▶ BIFROST
                         │ SPUTNIK — H523 · UM980     │
                         │ raw observables, 5 Hz      │ ── PPS + NMEA, the time port ──▶ KRONOS
                         └────────────────────────────┘
```
