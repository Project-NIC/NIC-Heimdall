# Эталонный код архива — Python и C

[English](README.md) · [Čeština](README.cs.md) · **Русский**

Эталонная библиотека, которую называет `MLF.md`, на Python и на C: MLF и NRC в том виде, как их фиксируют
`MLF.md` и `NRC.md`, и обе записывают те же байты, и измерение, которое решает вопрос
о его степенях сжатия относительно Steim-2 на записанных рядах. Ничего из этого пока не работает на
центральном блоке; центральный блок будет записывать через C.

**Здесь только профили Heimdall, на ядрах из NIC-SDK**: контейнер MLF и кодер рядов NRC находятся
в NIC-SDK (`tools/mlf.py`, `tools/nrc.py`, `mlf/`, `nrc/`), в клоне NIC-SDK рядом с этим
репозиторием или там, куда указывает `NIC_SDK`; сами ядра проверяет `tests/test_mlf.py` в NIC-SDK.

| файл | что |
|---|---|
| `hnrc.py` | кодер и декодер NRC: битовый поток, пять режимов, разбиения Райса, опорный канал, раскладка, составленная из полей и из байтов, которые ни одно поле не покрывает, раскладка NUMBER у Argus по его позициям |
| `hmlf.py` | MLF в памяти: заголовок и его секции, из `LAYOUT` и `UNIT` — раскладка, которой кодирует NRC, сегменты, закодированные сырыми и через NRC, с записью более короткого, конфигурации, кадрирование COBS, записи описания и двоичный поиск по ним, журнал событий, путь, правила записи и отправки по кадрам и блокам ModBus; читатель, который при потере описания находит объекты файла по нулям |
| `session.py` | сообщения сеанса выгрузки по `../../PROTOCOL.md` §6 — HELLO, CURSOR, ARCHIVE с цепным тегом, ACK, LIVE, WINDOW — вырезка файла от курсора и для окна и файл, собранный сервером из пакетов |
| `sdk.py` | где найти ядра NIC-SDK — рядом с этим репозиторием или в `NIC_SDK`; `hnrc.py` и `hmlf.py` импортируют его первым |
| `tests/test_hnrc.py` | случаи, перечисленные в `NRC.md`, на синтетических записях; каждый проходит туда и обратно байт в байт |
| `tests/test_damaged.py` | потоки обрезанные, удлинённые, с инвертированными битами, перезаписанные и выдуманные: каждый либо отклоняется с `ValueError`, либо декодируется, но никогда не падает и не зависает; обрезанный или удлинённый всегда читается как повреждённый. `NRC_FUZZ_SEED` и `NRC_FUZZ_ROUNDS` расширяют проверку |
| `tests/test_hmlf.py` | MLF на синтетических файлах: Quake, у которого посреди файла меняется раскладка, блоки Palatine, NUMBER Argus, журнал событий, файл, заполненный до конца, — каждый прочитан обратно запись за записью; повреждённый объект пропущен, потерянное описание восстановлено; что оставляет каждое правило |
| `tests/test_session.py` | каждый тестовый файл, отправленный целиком и от курсора и собранный обратно в байты карты; поддельный, пропущенный, переставленный и повторённый пакет отвергнут; вырезка окна; каждое сообщение прочитано обратно |
| `c/hnrc.h` · `c/hnrc.c` | тот же кодер и декодер на C99, зависящий только от malloc и free; собирается с `-ffp-contract=off`, чтобы предиктор округлял каждую операцию в double так же, как Python, а автокорреляцию суммирует точно, в 128 битах |
| `c/hmlf.h` · `c/hmlf.c` | тот же контейнер на C99 поверх `hnrc.c`: построение объектов, писатель, который держит файл в памяти и дописывает в него, как центральный блок, читатель, правила |
| `c/session.h` · `c/session.c` | тот же сеанс на C99 со своими SHA-256 и HMAC |
| `c/hnrc_tool.c` · `c/Makefile` | C, управляемый через stdin и stdout, для `tests/test_c.py` |
| `tests/test_c.py` | C против Python: сообщения сеанса, HMAC против RFC 4231, пакеты ARCHIVE, проверенные обоими, вырезки; потоки кадров через правило записи и правило отправки; файлы MLF, записанные обоими и сравненные байт в байт и прочитанные обоими целыми и с перевёрнутыми битами; все случаи NRC выше и случайные сегменты — любая ширина поля, оба порядка байтов, опорные каналы, крайние и переполняющиеся значения, секунды где угодно в 32 битах — закодированные обоими и сравненные байт в байт, каждый поток прочитан обратно на C, и каждый повреждённый поток оба оценивают одинаково, с теми же записями. `NRC_C_SEED` и `NRC_C_ROUNDS` расширяют его |

Экспортёры, которые читают эти файлы уже после, находятся в [`../export/`](../export/).

```
python3 tests/test_hnrc.py
python3 tests/test_damaged.py
python3 tests/test_hmlf.py
python3 tests/test_session.py
python3 tests/test_c.py                 # builds c/ with $CC, which may carry flags
NRC_RUN=qemu-arm CC="arm-linux-gnueabihf-gcc -static" python3 tests/test_c.py   # on a 32-bit ARM
```

**NRC измеряется на открытых записях** инструментом `tools/nrcmeasure.py` из NIC-SDK, рядом Steim-2;
как скачать ряды, говорит README NIC-SDK.
