# Эталонный код архива — Python и C

[English](README.md) · [Čeština](README.cs.md) · **Русский**

Эталонная библиотека, которую называет `HMC.md`, на Python и на C: HMC и HCC в том виде, как их фиксируют
`HMC.md` и `HCC.md`, и обе записывают те же байты, и измерение, которое решает вопрос
о его степенях сжатия относительно Steim-2 на записанных рядах. Ничего из этого пока не работает на
центральном блоке; центральный блок будет записывать через C.

| файл | что |
|---|---|
| `hcc.py` | кодер и декодер HCC: битовый поток, пять режимов, разбиения Райса, опорный канал, раскладка, составленная из полей и из байтов, которые ни одно поле не покрывает, раскладка NUMBER у Argus по его позициям |
| `hmc.py` | HMC в памяти: заголовок и его секции, из `LAYOUT` и `UNIT` — раскладка, которой кодирует HCC, сегменты, закодированные сырыми и через HCC, с записью более короткого, конфигурации, кадрирование COBS, записи описания и двоичный поиск по ним, журнал событий, путь, правила записи и отправки по кадрам и блокам ModBus; читатель, который при потере описания находит объекты файла по нулям |
| `session.py` | сообщения сеанса выгрузки по `../../PROTOCOL.md` §6 — HELLO, CURSOR, ARCHIVE с цепным тегом, ACK, LIVE, WINDOW, BOARD — вырезка файла от курсора и для окна и файл, собранный сервером из пакетов |
| `steim2.py` | упаковщик и распаковщик Steim-2 — кодек miniSEED, с которым сравнивается HCC, проверенный по числу кадров libmseed |
| `measure.py` | бит на отсчёт для Steim-2 и для каждого режима HCC на записанных трассах, по длине сегмента; `--ref` кодирует парные каналы друг относительно друга |
| `tests/test_hcc.py` | случаи, перечисленные в `HCC.md`, на синтетических записях; каждый проходит туда и обратно байт в байт |
| `tests/test_damaged.py` | потоки обрезанные, удлинённые, с инвертированными битами, перезаписанные и выдуманные: каждый либо отклоняется с `ValueError`, либо декодируется, но никогда не падает и не зависает; обрезанный или удлинённый всегда читается как повреждённый. `HCC_FUZZ_SEED` и `HCC_FUZZ_ROUNDS` расширяют проверку |
| `tests/test_hmc.py` | HMC на синтетических файлах: Quake, у которого посреди файла меняется раскладка, блоки Palatine, NUMBER Argus, журнал событий, файл, заполненный до конца, — каждый прочитан обратно запись за записью; повреждённый объект пропущен, потерянное описание восстановлено; что оставляет каждое правило |
| `tests/test_session.py` | каждый тестовый файл, отправленный целиком и от курсора и собранный обратно в байты карты; поддельный, пропущенный, переставленный и повторённый пакет отвергнут; вырезка окна; каждое сообщение прочитано обратно |
| `c/hcc.h` · `c/hcc.c` | тот же кодер и декодер на C99, зависящий только от malloc и free; собирается с `-ffp-contract=off`, чтобы предиктор округлял каждую операцию в double так же, как Python, а автокорреляцию суммирует точно, в 128 битах |
| `c/hmc.h` · `c/hmc.c` | тот же контейнер на C99 поверх `hcc.c`: построение объектов, писатель, который держит файл в памяти и дописывает в него, как центральный блок, читатель, правила |
| `c/session.h` · `c/session.c` | тот же сеанс на C99 со своими SHA-256 и HMAC |
| `c/hcc_tool.c` · `c/Makefile` | C, управляемый через stdin и stdout, для `tests/test_c.py` |
| `tests/test_c.py` | C против Python: сообщения сеанса, HMAC против RFC 4231, пакеты ARCHIVE, проверенные обоими, вырезки; потоки кадров через правило записи и правило отправки; файлы HMC, записанные обоими и сравненные байт в байт и прочитанные обоими целыми и с перевёрнутыми битами; все случаи HCC выше и случайные сегменты — любая ширина поля, оба порядка байтов, опорные каналы, крайние и переполняющиеся значения, секунды где угодно в 32 битах — закодированные обоими и сравненные байт в байт, каждый поток прочитан обратно на C, и каждый повреждённый поток оба оценивают одинаково, с теми же записями. `HCC_C_SEED` и `HCC_C_ROUNDS` расширяют его |

```
python3 tests/test_hcc.py
python3 tests/test_damaged.py
python3 tests/test_hmc.py
python3 tests/test_session.py
python3 tests/test_c.py                 # builds c/ with $CC, which may carry flags
python3 measure.py recording.mseed --seconds 1,2,4,8,16,32
python3 measure.py obs.min --seconds 60,300,900,3600      # IAGA-2002, nT × 100
```

`measure.py` читает miniSEED через obspy, а IAGA-2002 — сам; трасса — это один целочисленный ряд,
а ширина поля — наименьшая ширина в целых байтах, в которую помещаются её значения.
