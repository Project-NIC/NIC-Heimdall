# Экспортёры

[English](README.md) · [Čeština](README.cs.md) · **Русский**

То, что берёт мир, записанное из архива задним числом, так, как каждый из них вводит
[`../EXPORTERS.md`](../EXPORTERS.md). **Ничто здесь не является записью станции**: запись — это файлы
MLF и библиотека в [`../ref/`](../ref/), которая их пишет и читает; экспортёр их только читает, на
сервере или ноутбуке, и одни и те же файлы и один и тот же запрос всегда дают одни и те же байты.
**miniSEED со StationXML и IAGA-2002 — из NIC-SDK** (`tools/mlf2mseed.*`, `tools/mlf2iaga.*`), для
любого профиля; Heimdall даёт им свой клей — чтение своих записей.

| файл | что |
|---|---|
| `glue.py` | клей Heimdall для экспортёров NIC-SDK: канал из `LAYOUT` по имени или как `#c`, n · rows в секунду; станция из `STATION`; GPS − UTC из `TIME`; отсчёты сегмента через эталонную библиотеку, CLIPPED и DISTURBED как биты качества SEED; ориентация SEED по имени, иначе номер канала |
| `tables.py` | каждая запись адреса с раскладкой, правилом и GPS − UTC, действующими в её момент; один файл CSV на адрес; таблицы SQLite, которые PostgreSQL берёт как есть, рядом каталог файлов |
| `tests/test_mseed.py` | файл синтетического Quake через NIC-SDK и клей, прочитанный обратно ObsPy отсчёт за отсчётом, пропуск и биты качества на своих местах, коды трёх осей, StationXML, валидный по схеме FDSN |
| `tests/test_iaga.py` | сутки синтетического магнитометра на 32 Гц через NIC-SDK и клей, прочитанные обратно по фиксированным столбцам: станция, минута пропуска, минута там, где её дают фильтры |
| `tests/test_tables.py` | CSV и SQL значение за значением против чтения каждого тестового файла самой эталонной библиотекой, более поздняя запись запоздавшего кадра сохранена, каталог — одна строка на сегмент и конфигурацию |

```
python3 ../../../../NIC-SDK/tools/mlf2mseed.py glue.py OUT.mseed NET STA LOC '#0' FILE…
python3 ../../../../NIC-SDK/tools/mlf2iaga.py glue.py DIR CODE SOURCE minute magX,magY,magZ FILE…
python3 tests/test_mseed.py          # needs ObsPy
python3 tests/test_iaga.py
python3 tests/test_tables.py
```

NIC-SDK находится рядом с этим репозиторием или там, куда указывает `NIC_SDK` (`../ref/sdk.py`);
форматы держат его собственные тесты — кадры Steim-2, фильтры против SciPy, минуты Будкова.
