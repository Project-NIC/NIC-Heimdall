# Экспортёры

[English](README.md) · [Čeština](README.cs.md) · **Русский**

То, что берёт мир, записанное из архива задним числом, так, как каждый из них вводит
[`../EXPORTERS.md`](../EXPORTERS.md). **Ничто здесь не является записью станции**: запись — это файлы
MLF и библиотека в [`../ref/`](../ref/), которая их пишет и читает; экспортёр их только читает, на
сервере или ноутбуке, и одни и те же файлы и один и тот же запрос всегда дают одни и те же байты.

| файл | что |
|---|---|
| `export.py` | ряд одного канала, прочитанный из файлов адреса в её моменты UTC; miniSEED 2.4 со Steim-2 в записях по 512 B и FDSN StationXML 1.2; IAGA-2002 с минутным фильтром INTERMAGNET и фильтром нижних частот USGS до 1 Гц, масштабированным по частоте |
| `tables.py` | каждая запись адреса с раскладкой, правилом и GPS − UTC, действующими в её момент; один файл CSV на адрес; таблицы SQLite, которые PostgreSQL берёт как есть, рядом каталог файлов |
| `tests/test_mseed.py` | файлы синтетического Quake, экспортированные и прочитанные обратно ObsPy отсчёт за отсчётом, пропуск и биты качества на своих местах, кадры против `../ref/steim2.py`, StationXML, валидный по схеме FDSN |
| `tests/test_iaga.py` | фильтры против фильтров SciPy; собственные минуты Будкова из его собственных секунд с точностью до округления; сутки синтетического магнитометра на 32 Гц, прочитанные обратно по фиксированным столбцам |
| `tests/test_tables.py` | CSV и SQL значение за значением против чтения каждого тестового файла самой эталонной библиотекой, более поздняя запись запоздавшего кадра сохранена, каталог — одна строка на сегмент и конфигурацию |

```
python3 tests/test_mseed.py          # needs ObsPy
python3 tests/test_iaga.py           # needs SciPy; BDV_SEC and BDV_MIN name Budkov's day, if fetched
python3 tests/test_tables.py
```

Тестовые файлы — из эталона (`../ref/tests/test_hmlf.py`); как скачать сутки Будкова, описано в
`../ref/README.md`.
