# Steinmetz — the graveyard

Rejected alternatives and superseded states, with the reason. Nothing returns from here and
nothing is deleted from it. The board's graveyard is `../WHY.md`.

## Glass to the roof — rejected

A fibre buys isolation and immunity the copper board already has (`G-I-N-025`, isolated through
`SN6505B` and `ISO1450`, is written for 500 m in lightning country) and **loses on everything a
vehicle does to a cable**: the bend at the gland, the door seal, vibration at the connector, no
field repair without tools. The magnetic argument is even: the feed cores carry the sub-512 kHz
currents in both builds, and the roof board itself carries the data pairs' 2²² and above. Four 1×9
modules a link against one `SN6505B` and two `ISO1450` an end.

## 48 V on the hybrid cable's spare pairs, the return shared with the 485 — rejected

A NodBus run uses all four pairs, and a shared return puts the feed's drop and switching current
into the signal reference **the isolated line side keeps clean**. On 3–5 m 48 V buys nothing —
12 V at 0,4 A on 0,75 mm² drops 55–90 mV there and back — and costs a source cell below and a boundary-mode flyback
beside the rods.

## The GNSS receiver in the roof box — rejected

Polaris is a carrier, fed 3,3 V and booted by Kronos. On the roof it would need **a second link to
Kronos, a second pair of communication boards and a host to feed it**. The receiver stays in the
enclosure, only the coax long; the windscreen sees the sky as well as the roof.

## A 3-bit class field — rejected

Eight classes cost a bit of amplitude for nothing: **arc against corona against partial discharge
is a property of a source over time** (rate, phase, drift over days), already in the source-state
record. The event keeps Tesla's two bits and layout, so one decoder reads both.

## Lightning as a class of the record — dropped

The image is a line monitor: a stroke the rods still see is impulsive, not mains-locked, and
**falls to UFO** like anything else that is not a line.

## A base board of its own under this name — superseded by Proteus

The cabin base was first Steinmetz's own board, so **one name covered a unit and a board**. The
board is Proteus (`../../proteus/`); Steinmetz is the unit alone, as Pip is.
