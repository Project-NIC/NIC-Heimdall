# marconi/models — ориентация рамки

[English](README.md) · [Čeština](README.cs.md) · **Русский**

Арифметика, стоящая за разделом *One loop, standing, and its two nulls are a siting condition* в
[`../CONSTRUCTION.md`](../CONSTRUCTION.md): азимут по дуге большого круга от станции до каждого
контролируемого передатчика и плоскость кольца, повёрнутая на угол, при котором максимален
`|cos(bearing − plane)|` для худшей цели. Кольцо закрепляется болтами под напечатанным углом до
подъёма мачты; в эксплуатации ничего не вращается.

- [`pointing.py`](pointing.py) — чистый Python, без пакетов. Запустите его с координатами станции:

```
python3 pointing.py 50.08 14.43
```

выводит плоскость и нули диаграммы, худшую цель и таблицу азимута, угла от плоскости и отклика для
каждого передатчика. Встроенная таблица содержит постоянные станции времени и маркеры из
[`../BAND.md`](../BAND.md), положение которых опубликовано; площадка передаёт собственный список
в виде CSV (`name,kHz,lat,lon`) третьим аргументом. Расчётная таблица в `../CONSTRUCTION.md` — это
вывод данной программы для 50,08° N 14,43° E.
