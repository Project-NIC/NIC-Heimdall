# Daedalus — чертежи

[English](README.md) · [Čeština](README.cs.md) · **Русский**

Механические конструкторские чертежи станции: мачта и её кронштейны, заземление, прокладка кабелей,
шкафы и подземная камера. Основание, зонд или морская линия чертятся вместе с блоком, который их
использует. Стадия проектирования — пополняется по мере создания чертежей (SVG / CAD).

Текст о конструкции, который иллюстрируют эти чертежи, — в [`../CONSTRUCTION.md`](../CONSTRUCTION.md).
