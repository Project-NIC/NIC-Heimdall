# Daedalus — drawings

Mechanical construction drawings for the station: the mast and its brackets, the earth, the
cable routing, the enclosures and the vault. A seat, a sonde or a sea run is drawn with the unit
that uses it. Design-stage — filled as the drawings are made (SVG / CAD).
