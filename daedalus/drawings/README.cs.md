# Daedalus — výkresy

[English](README.md) · **Čeština** · [Русский](README.ru.md)

Strojní konstrukční výkresy stanice: stožár a jeho držáky, uzemnění, vedení kabelů, skříně
a podzemní komora. Usazení, sonda nebo mořská trasa se kreslí spolu s jednotkou, která je používá.
Fáze návrhu — doplňuje se tak, jak výkresy vznikají (SVG / CAD).

Text o stavbě, který tyto výkresy ilustrují, je v [`../CONSTRUCTION.md`](../CONSTRUCTION.md).
